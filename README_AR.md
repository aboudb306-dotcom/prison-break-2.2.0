# PRISON BREAK Beta — مشروع بناء APK

هذه الحزمة تغلّف ملفات لعبتك الحالية داخل تطبيق Android باستخدام Apache Cordova، مع إبقاء ملف اللعبة الأصلي `www/index.html` كما هو. إعدادات التطبيق أفقيّة وملء الشاشة، وعنوان WebSocket والتحديثات الموجودان داخل اللعبة لم يتم تغييرهُما.

## طريقة سهلة لبناء APK عبر GitHub Actions

1. فكّ ضغط هذا الملف على جهاز كمبيوتر.
2. أنشئ مستودعًا جديدًا على GitHub وارفع **محتويات هذا المجلد** إليه (وليس ملف ZIP نفسه).
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Prison Break APK** ثم **Run workflow**. ويمكن أن يبدأ البناء تلقائيًا عند رفع الملفات إلى الفرع `main`.
5. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
6. نزّل `Prison-Break-APK`، ثم فك ضغطه لتحصل على `app-debug.apk`.
7. انقل APK إلى هاتفك وثبّته. قد يطلب Android السماح بالتثبيت من مصدر الملفات الذي استخدمته.

## البناء على الكمبيوتر

المتطلبات: Node.js 20، Java JDK 17، Android SDK مع Android SDK Platform 35 وأدوات البناء.

من داخل المجلد شغّل:

```bash
npm install
npx cordova platform add android@14.0.1
npx cordova build android --debug
```

ستجد APK هنا:
`platforms/android/app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات مهمة

- هذا APK تجريبي موقّع بمفتاح debug، مناسب للاختبار والمشاركة التجريبية. للنشر الرسمي أو التحديثات المستمرة، أنشئ مفتاح توقيع release خاصًا واحفظه بأمان.
- احتفظ بنفس `widget id` (`com.darkkingdom.prisonbreak`) عند بناء الإصدارات اللاحقة حتى يستطيع Android تحديث التطبيق بدل اعتباره تطبيقًا مختلفًا.
- لم أغيّر كود اللعبة أو السيرفر. نجاح البناء لا يضمن وحده أن كل ميزة تعمل داخل WebView؛ اختبر تسجيل الدخول والغرف والاتصال والتحديثات على الهاتف بعد التثبيت.
- لا ترفع كلمات مرور أو مفاتيح توقيع إلى مستودع عام.
